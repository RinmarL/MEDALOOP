# メダル・インクリメンタルゲーム 仕様書 (SPECIFICATION)

## 1. プロジェクト概要
傾いた盤面を滑る2D円形メダルの物理演算をベースにした、ブラウザ（PC・スマホ両対応）で20分〜60分遊べるラウンド制インクリメンタルゲーム。
ビジュアルテーマは**「現代スマートスロット（ネオン・スマスロ：ダーククローム筐体 × シアン＆マゼンタLED × カーボン盤面 × 3Dコインが積まれる下皿 × 3Dメダル投入口）」**。

---

## 2. 物理演算仕様（厳守パラメータ）
傾いた盤面を滑る、同じ重さの2D円形メダル。単位は `px`・`秒`。

### 基本パラメータ
- **物理更新ステップ (`dt`)**: `1 / 240` 秒（固定タイムステップ）
- **メダル半径 (`R`)**: `15` px（直径 `30` px）
- **下向き重力加速度 (`g`)**: `3000` px/s²（パチンコ・スマートボール特有の落ち着いた軌道追跡のため緩和）
- **最高落下速度（終端速度キャップ）**: `500` px/s（重力加速の上限リミッター）
- **滑り摩擦による減速度 (`friction`)**: `900` px/s²（一定減速、速度反転なし）
- **投入時の横速度 (`vx_init`)**: `-30` 〜 `+30` px/s の一様乱数
- **投入時の下向き速度 (`vy_init`)**: `40` px/s
- **メダル同士の反発係数 (`restitution`)**: `0.62`
- **衝突時の接線方向の速度保持率 (`tangent_collision_retention`)**: `0.96`
- **接触扱いにする法線相対速度閾値 (`contact_normal_speed_threshold`)**: `50` px/s 未満
- **接触中の接線方向の速度保持率 (`tangent_contact_retention`)**: `0.985` ／更新（1/240秒あたり）

## 4. メダルパートと盤面ギミック
- **メダルサイズの適正化**:
  - メダル半径を `R=15px`（直径 `30px`、従来42pxから約30%縮小）へ最適化。盤面の有効面積を実質2倍以上に拡大し、メダルの詰まり防止と軽快な物理バウンドを実現。
- **中央3連大型ネオンバンパー（トライアングル配置）**:
  - 盤面中央に上左（r=23）、上右（r=23）、下中央（r=25）の3基を配置。通常ピンより強力な反発係数（1.05〜1.35）を持ち、メダルがバンパー間を激しくピンポン往復する。
- **釘（ピン）の配置（ほんのり約25本）**:
  - 上部振り分け（7本）、左右壁際ガード（4本）、バンパー下中段（5本）、下部スロット境界スプリット（9本）の計25本。抜け感と左右への自然な散らばりを両立。
- **トグル式5スロットJACKPOT ＆ 10枚射出フィーバー**:
  - 下部の各スロット（`x1`, `x2`, `x4`, `x2`, `x1`）の上にネオンLEDインジケーターを設置。
  - メダルが入賞するたびにランプが **点灯 ⇔ 消灯（トグル）**。
  - **全5箇所が同時に点灯した瞬間に「JACKPOT FEVER」が発動**。
  - 画面揺れ・レインボーフラッシュ・ファンファーレとともに、盤面**左上・右上のサイバーシューターから各5枚（計10枚）のメダルが中央へ向けて勢いよく連続射出**される。発動後、ランプは全消灯（リセット）。
- **制限時間の初期値**:
  - ベースの制限時間は **`15.0` 秒**。
  - スキルツリー内に **「制限時間 +1秒（最大3回強化＝+3秒）」のノードを計5マス** 配置する（最大 +15秒、合計最大 30.0秒）。
- **盤面のラッキーリング（通過ゲート：案14）**:
  - 盤面のピン間の空間に、物理挙動を妨げない光る通過リング（`×2 CHARGE`：通過したメダルの得点倍率2倍ブースト、または `SPLIT +1`：通過したメダルがその場で2枚に分裂）が出現する。
  - 通過するとエフェクトとともに効果が発動し、一定時間後に別の位置へ再出現する。
- **下皿・投入口のサイズと3Dコイン表現**:
  - 下皿と投入口の領域の高さをコンパクトに引き締め、下皿・回収移動・投入口のメダルをすべて3Dコイン表現に統一する。
  - 下皿のスタック列は8列（間隔30px）に最適化。

## 5. スキルツリー画面のUI仕様
- スキルツリー画面（強化画面）では、上部の筐体ヘッダー領域（`🏠 / SCORE: / TIME: TREE / 🔊`）は非表示にし、画面を広く使う。
- **全体世界観・ビジュアルテーマ（天体・宇宙・星図盤：Celestial Astrolabe & Cosmos）**:
  - **背景**: 宵闇の深宇宙コズミック・ヴォイド（インディゴネイビー深奥グラデーション）に、たなびく星雲ダスト（シアン・ローズ・黄金）と瞬く大小の星団・4点星座星（✦）を描画する。
  - **天球儀軌道リング（第1〜第4円の完全等間隔軌道）**: 起点コア `c0 (0, 0)` を中心に、**第1円 (`R1=64`)・第2円 (`R2=128`)・第3円 (`R3=192`)・第4円 (`R4=256`)** の4本の完全等間隔（64px刻み）な金色同心円軌道を描画し、全42ノード（`c0` を除く41ノードすべて）がこの4つの円軌道上に完全一致で配置される。同一円軌道上の隣接ノード接続ラインは円軌道に沿う最短円弧で描画される。最外周 `R=295` には水色の外枠リング・黄道天測計目盛り（6度刻み）・角度刻印（`20° ECLIP`, `30° CELEST`, `AST 350°`, `POLARIS 0°`）を配する。
  - **3D天体球体ノード（Planetary Spheres）**:
    - 単なる平坦なボタンを排し、息を呑む3D天体球体（恒星・惑星・パルサー・新月）として描画する。
    - **中心・太陽コアノード**: 黄金のソーラーコロナと太陽フレアを纏う恒星球体。
    - **解放済みノード**: 大気光（Atmospheric Corona）を放つサファイア惑星球体（地球・天王星）。
    - **解放可能ノード**: ネビュラピンクに脈動する星雲幼星・パルサー球体。
    - **未解放ノード**: 皆既日食／新月（漆黒の深宇宙球体に極細の月蝕ダイヤモンドリング）。
    - **選択ノード**: スターライト光輪に加え、周囲を公転する衛星光点をリアルタイム描画する。
  - **下部ノード詳細パネル（天体星図盤・コズミックタブレット）**:
    - 茶色い木枠・家具調配色を全廃し、深宇宙コズミックネイビー（`rgba(12, 18, 42, 0.94)`）に星雲光彩が溶け込む半透明タブレットとする。外枠はスターライトシアン＆ゴールドの二重天測リム。
    - タイトルは黄金星光（`✦`）を冠し、Lv表示はシアン発光の惑星軌道カプセルとする。
    - **解放ボタン（Active時）**: 星核エネルギーを放つシアン〜ネビュラピンクの星彩グラデーション＋天体ハイライト。文言は `✦ 天体解放 (X PT)` または `✦ 星核強化 (X PT)`。
    - **解放ボタン（Disabled時）**: 従来の灰色プラスチックを全廃し、「休眠天体・新月スロット」として深青の透き通る星空ガラス＋淡い星屑リム（`✧ 天体解放 (X PT)` / `★ 完全解放 (MAX)`）とする。
    - **ホーム帰還ボタン**: 白プラスチックピルを全廃し、深青の天体羅針盤ボタン（`⟵ ホーム`）とする。
  - **拡大縮小（Zoom）機能**:
    - スマホでのピンチイン・アウト、PCでのマウスホイール、および右上の天体観測レンズ調補助ボタン（`+` / `-` / `⟲`）による直感的なズーム（0.55倍〜2.4倍）を常時サポートする。
